# 89TV

_Make a seasonal copy of your [7TV](https://7tv.app) emote set._

[89TV](https://89tv.youngmani.com) helps streamers and editors create Halloween or Christmas themed emote sets from
their existing 7TV emote sets.

How it works:

- Log in with your 7TV account. Your token stays in the browser and is only sent to 7TV servers.
- Select a theme, a base emote set, and a target emote set.
- Map emotes over one by one. There's no preset mapping, so you can choose between different variants of an emote.
- Aliased emotes have their aliases preserved, while searching for seasonal emotes using the original name.
- Update existing seasonal sets from last year by reviewing existing mappings and emotes that were removed from the
  base set since last year.

Try the [demo](https://89tv.youngmani.com/demo)!

89TV is an unofficial fan project and is not affiliated with 7TV.

## Local development

```bash
pnpm install
pnpm dev     # http://localhost:3000
pnpm build   # static site in ./out
```
